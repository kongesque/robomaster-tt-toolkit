# DJI RoboMaster TT (Tello Talent)

Manufacturer: Ryze Technology / DJI RoboMaster

Model number: TLW004

Type: Programmable educational quadcopter

Released: 2020


## Technical specifications

| Specification           | RoboMaster TT                     |
| ----------------------- | --------------------------------- |
| Weight                  | 87 g, with propeller guards       |
| Dimensions              | 98 × 92.5 × 41 mm (aircraft body) |
| Propellers              | 3 inches                          |
| Maximum flight time     | 13 minutes                        |
| Maximum speed           | 8 m/s (28.8 km/h)                 |
| Maximum flight distance | 100 m                             |
| Maximum flight height   | 30 m                              |
| Battery                 | 1,100 mAh, 3.8 V LiPo             |
| Camera                  | 5 MP, 2592 × 1936                 |
| Video                   | 720p at 30 FPS                    |
| Stabilization           | Electronic image stabilization    |
| Aircraft communication  | 2.4 GHz Wi-Fi                     |
| Charging                | Micro-USB                         |

Manufacturer specifications under ideal conditions; actual flight time and range can be lower.&#x20;

## Programming and expansion features

The TT is particularly useful for computer vision and AI experiments.

| Feature                  | Details                                       |
| ------------------------ | --------------------------------------------- |
| Expansion processor      | ESP32-D2WD, dual-core 160 MHz                 |
| Programming              | Python via SDK, MicroPython, Arduino, Scratch |
| Control protocol         | UDP, Tello SDK 3.0                            |
| Real-time control        | Roll, pitch, throttle, yaw                    |
| Expansion interfaces     | GPIO, UART, I²C, SPI, PWM                     |
| Expansion Wi-Fi          | 2.4 / 5.8 GHz                                 |
| Optional display         | 8×8 red/blue LED matrix                       |
| Optional distance sensor | ToF, up to 1.2 m                              |
| Positioning              | Downward vision and infrared sensors          |
| GPS                      | None                                          |

Important flight-time detail: The 13-minute figure applies without the expansion kit. With the kit mounted, DJI's manual gives approximately 8 minutes.&#x20;
